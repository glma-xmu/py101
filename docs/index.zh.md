# Python与经济大数据

本课程带你上手 **Python** 与**大数据**，并聚焦它们在**经济学**中的应用。本站为中英双语 —— 可使用顶部的**语言切换**按钮在 English 与中文之间切换。

!!! tip "如何使用本站"
    使用左侧导航菜单浏览各章节。页面上的大多数代码都是**可运行的** —— 按 *Run* 即可在浏览器中执行、修改并重新运行。可使用右上角的搜索框快速跳转到任意主题。
